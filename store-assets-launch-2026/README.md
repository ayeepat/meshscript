# Пакет для Chrome Web Store

Готовый набор материалов для русской карточки расширения СМЭШ AI.

## Что загружать

1. Иконка расширения: `icon/icon-128.png`
2. Скриншоты в указанном порядке:
   1. `screenshots/01-homework.png`
   2. `screenshots/02-test-fill.png`
   3. `screenshots/03-files.png`
   4. `screenshots/04-solution.png`
   5. `screenshots/05-gdz.png`
3. Маленькая промоплитка: `promo/small-tile-440x280.png`
4. Большой промобаннер, если поле доступно: `promo/marquee-1400x560.png`
5. Текст карточки: `copy/listing-ru.md`

Техническая сверка с официальной документацией находится в `copy/official-requirements.md`.
Результат контрольного просмотра и остаточный риск по материалу ГДЗ находятся в `qc/verification.md`.

## Размеры

| Материал | Размер | Статус |
| --- | --- | --- |
| Иконка | 128 × 128 PNG | Готово |
| Скриншоты | 1280 × 800 PNG | 5 файлов, готово |
| Маленькая промоплитка | 440 × 280 PNG | Готово |
| Большой промобаннер | 1400 × 560 PNG | Готово, необязательно |

## Принцип оформления

На скриншотах сохранён настоящий интерфейс СМЭШ AI. Добавлены только заголовки, короткие пояснения, рамки и указатели. Использованы фирменные Unbounded и Manrope, тёплый фон сайта и бирюзовый цвет бренда.

Сгенерированное изображение использовано только как спокойный фоновый слой для промоматериалов. Реальный интерфейс, логотип и текст собраны отдельно и не изменены генератором. Исходный запрос сохранён в `brand/imagegen-prompt.txt`.

## Видео

Промовидео в этот пакет не включено. Исходная заставка Chrome Web Store выполнена на английском, поэтому она нарушила бы единый русский язык карточки. Видео можно добавить позже через ссылку на YouTube после локализации заставки.

## Что намеренно не делалось

В пакет не входят инструкции для проверяющего, обоснования разрешений, настройки privacy practices и проверка аккаунта разработчика. Код расширения не менялся.
