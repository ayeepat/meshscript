# Chrome Web Store assets

These files are ready for the Chrome Developer Dashboard:

- `screenshots/*.png`: real product captures at 1280×800;
- `promo/small-tile-440x280.png`: required small promo tile;
- `promo/marquee-1400x560.png`: optional marquee tile.

The source captures live under `motion/public/assets/v3`. The store images do
not contain mock ratings, user counts, testimonials, or badges. Regenerate the
four screenshots from the release recordings if the visible extension UI
changes.
