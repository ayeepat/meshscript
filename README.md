# СМЭШ AI

Расширение для Chromium-браузеров (Manifest V3, минимум Chrome 140). Оно читает
домашнее задание на той странице электронного дневника МЭШ, которую пользователь
уже открыл сам, и показывает разбор в отдельной вкладке. Условие не нужно
никуда копировать.

Сайт продукта — [smeshai.xyz](https://smeshai.xyz/). Расширение опубликовано в
[Microsoft Edge Add-ons](https://microsoftedge.microsoft.com/addons/detail/jockjfcmofofpjjpoljclneoabhcioao);
сборка 1.0.0 подана в Chrome Web Store.

**СМЭШ AI — независимый продукт.** Он не связан с МЭШ, mos.ru и Департаментом
образования и науки города Москвы, не является их официальным сервисом и не
выдаёт себя за него.

## Единственное назначение

Помогать школьнику разбирать домашние задания на открытых им самим страницах
электронного дневника МЭШ с помощью ИИ. Всё остальное в расширении —
обслуживание этой задачи: лицензия, согласие на обработку, локальная история и
настройки.

## Как это работает

1. **Установка.** После установки открывается полноэкранное знакомство
   (`src/welcome/welcome.html`) на русском языке: шесть шагов — установка,
   лицензия за 149 ₽ в месяц, домашка, тесты, файлы и ГДЗ — со скриншотами из
   `assets/onboarding/`. Крестик спрашивает подтверждение, потому что второго
   показа не будет: знакомство открывается **один раз на устройство**, и это
   решает `src/lib/onboarding.js`. Запись о показе делается ДО открытия вкладки,
   переживает «Удалить локальные данные» и не зависит от лицензии, поэтому ни
   обновление расширения, ни продление ключа его не повторяют. Тем, кто
   установил расширение до появления знакомства, оно открывается ровно один раз
   при обновлении (ветка `update` в сервис-воркере).
2. **Согласие.** При первом запуске попап показывает один чекбокс: «Я принимаю
   условия использования и политику конфиденциальности» со ссылками на оба
   документа. Перечисления в интерфейсе больше нет — что именно отправляется,
   кому и на какой срок, описано **только** в этих документах, включая
   анонимную статистику: отдельный переключатель статистики убран, и та же
   галочка включает её (`CONSENT_VERSION = 3`, см. `src/lib/consent.js`).
   Поэтому тексты на smeshai.xyz/terms и /privacy обязаны описывать и передачу
   данных ИИ-сервисам, и сбор статистики — в расширении этого больше не
   написано нигде. **До принятия согласия ни один сетевой запрос с содержимым
   задания не выполняется** — проверка живёт в `src/lib/consent.js`, и каждый
   исходящий обработчик в `src/background/service-worker.js` перепроверяет её
   ещё раз перед `fetch`. Согласие видно и отзывается в настройках, раздел
   «Конфиденциальность и данные»; там же кнопка «Удалить статистику и отключить
   сбор» — единственный оставшийся способ отказаться от статистики, не отзывая
   согласие целиком.
3. **Ключ доступа.** Иконка расширения → ⚙️ → «Лицензия» → поле «Ключ доступа».
   Ключ проверяется на сервере СМЭШ.
4. **Дневник.** Пользователь открывает
   `school.mos.ru/diary/homeworks/homeworks`. Контент-скрипт
   (`src/content/scraper.js`) читает карточки заданий за видимую неделю и
   группирует их по дням. Этот разбор целиком локальный: во время сканирования
   недели наружу не уходит ничего.
5. **Разбор.** По нажатию «Решить» на конкретной строке открывается вкладка с
   чатом, и только в этот момент выполняется первый запрос к ИИ — по одному
   заданию, которое выбрал пользователь.

Все запросы к ИИ идут через собственный прокси `ai.smeshapi.site` и требуют
активной лицензии. Выбора провайдера в интерфейсе нет, поля для чужого API-ключа
нет, и расширение не запрашивает разрешений ни на один домен ИИ-вендора.

## Возможности

- **Неделя целиком.** Задания за видимую неделю собираются в один список,
  каждый день — сворачивающийся блок. Слева в открытой вкладке лежат уроки
  недели, у каждого свой чат.
- **Ответ печатается потоком**, а не появляется через полминуты тишины.
- **«Кратко» / «Объяснить».** Переключатель в шапке чата: короткий ход решения
  или полный разбор с пояснениями.
- **Вложения задания.** Если к заданию приложен файл (документ, PDF,
  изображение), расширение забирает его из уже открытой сессии МЭШ пользователя.
  Загрузка ограничена доменами `school.mos.ru` и `uchebnik.mos.ru`, редиректы
  перепроверяются на каждом шаге. Не нашлось — расширение попросит приложить
  файл вручную.
- **Фото страницы учебника.** Ctrl/⌘+V прямо в поле ввода — скриншот или
  вырезанный фрагмент уходит в чат вместе с вопросом.
- **Кнопка на странице задания.** На страницах МЭШ (`school.mos.ru`,
  `uchebnik.mos.ru`) расширение рисует компактную кнопку: по явному нажатию оно
  разбирает то, что открыто на экране, и показывает объяснение.
- **Уточняющие вопросы.** Диалог продолжается в том же чате; «Решить заново»
  всегда рядом в шапке.
- **Повторное открытие — без нового запроса.** Закрыли вкладку и снова нажали
  «Решить» на том же уроке — развернётся сохранённый чат из локальной истории.
  Учитель изменил текст задания — ключ урока меняется вместе с ним, и задание
  разбирается заново.
- **История решений** лежит в настройках, разворачивается целиком и хранится
  только на устройстве 7 дней.

## Чего расширение не делает

- **Не входит в аккаунт.** Оно работает внутри уже открытой пользователем
  сессии МЭШ. Логина и пароля у него нет, форму входа оно не заполняет.
- **Не отправляет работу за пользователя.** Кнопку сдачи расширение не нажимает.
- **Не решает аудирование по звуку.** Расшифровка записи в этой сборке
  недоступна, и приложенный аудиофрагмент устройство не покидает: адаптеры
  провайдеров заменяют его текстовой пометкой (`fileToContentPart` в
  `src/lib/deepseek.js`). Нужен разбор — пришлите текст записи.
- **Не выполняет удалённый код.** В пакете нет `eval`, нет подгружаемых извне
  скриптов. Единственная удалённая конфигурация — подписанный ключом P-256
  конверт данных, значения из которого проверяются по вшитым в сборку спискам
  (`src/lib/remote-config.js`, `docs/RUNTIME-CONFIG.md`).
- **Не следит за пользователем.** Анонимная статистика без содержимого заданий
  входит в то же согласие, что и обработка данных (отдельного переключателя
  больше нет), отключается и удаляется кнопкой в настройках, а без согласия не
  отправляется вообще. Ни рекламы, ни партнёрских вставок в страницы расширение
  не добавляет.

## Разрешения

| Разрешение | Зачем |
|---|---|
| `storage`, `unlimitedStorage` | Только локально: настройки, согласие, состояние лицензии, история решений на 7 дней. `unlimitedStorage` — потому что встроенные в историю изображения выходят за обычную квоту `storage.local`. Синхронизация не используется; хранилище закрыто для контент-скриптов через `setAccessLevel`. |
| `activeTab` | По явному нажатию пользователя прочитать текст и снять снимок активной вкладки МЭШ. Любое другое происхождение страницы отбрасывается до захвата. |
| `scripting` | Внедрить контент-скрипты, читающие задания, — только на двух объявленных доменах МЭШ и только после действия пользователя. |
| `alarms` | Локальная уборка по расписанию: история — 7 дней, результат сканирования недели — 24 часа, ожидающие передачи файлов — 1 час. Сети не касается. |

| Домен | Зачем |
|---|---|
| `school.mos.ru`, `uchebnik.mos.ru` | Прочитать собственный дневник и задания пользователя и скачать вложения — внутри его же авторизованной сессии. |
| `ai.smeshapi.site` | Прокси СМЭШ и единственный адрес, куда уходит запрос к ИИ. Требует лицензию, анонимный идентификатор устройства и токен активации. |
| `smeshapi.site` | Проверка лицензии (`POST /verify`) и — только после принятия условий — анонимная статистика без содержимого. |
| `smeshai.xyz` | Один `GET` подписанного конверта конфигурации. Данные пользователя не отправляются. |

Полный разбор разрешений и потоков данных, с привязкой каждого пункта к коду, —
в [docs/STORE-REVIEW.md](docs/STORE-REVIEW.md). Тексты и чек-лист публикации —
в [docs/CHROME-WEB-STORE.md](docs/CHROME-WEB-STORE.md).

## Данные

- **Наружу уходит только то, что пользователь выбрал разобрать:** текст задания,
  снимок видимой страницы, приложенный файл. Всегда по HTTPS и всегда через
  прокси СМЭШ.
- **Токен сессии МЭШ** читается из `localStorage` самой страницы исключительно
  ради скачивания вложений пользователя и никуда больше не передаётся.
- **История — только локальная**, TTL 7 дней (`src/lib/history.js`), срок
  выдерживается и при чтении, и периодической уборкой через `alarms`.
- **Статистика — строго по согласию.** Событие содержит тип действия,
  каноническое название предмета, модель, семейство браузера, версию расширения,
  тип лицензии и случайный UUID устройства. Никогда — текст задания, ответы,
  файлы или ключ лицензии (`src/lib/telemetry.js`).
- Оплата происходит на сайте, а не в расширении; платёжные данные расширение не
  видит и не хранит.

## Доступ

Для ответов нужен ключ доступа СМЭШ; тарифы и покупка — на
[smeshai.xyz](https://smeshai.xyz/pricing/). Один ключ работает на одном
устройстве: перед переездом нажмите «Деактивировать ключ на этом устройстве» в
настройках. Если старого компьютера уже нет под рукой, отвязать ключ можно
командой `/sub` в [телеграм-боте](https://t.me/smeshaibot). Срок подписки
начинается с первой активации и при переносе не сдвигается.

Поддержка — [@smeshaibot](https://t.me/smeshaibot?start=support); кнопки
«Поддержка» в попапе и настройках ведут туда же.

## Установка вручную

1. Скачайте репозиторий (`Code` → `Download ZIP`) и распакуйте.
2. Откройте `chrome://extensions`.
3. Включите **Режим разработчика** — переключатель справа сверху.
4. **Загрузить распакованное расширение** → выберите распакованную папку.

## Разработчикам

Расширение — это корень репозитория: `manifest.json`, `src/` и `assets/`.
Сборки нет, в магазин уходит ровно тот код, который лежит здесь.

```sh
npm ci
npm run verify
npm run package:extension
npm run verify:package
```

`verify` — разбор исходников плюс все регрессии (`tests/`), включая инварианты
готовности к публикации. `package:extension` собирает детерминированный архив
для магазина, `verify:package` проверяет, что архив совпадает с исходниками.
Те же команды CI гоняет на каждый push и pull request.

Серверные части описаны у себя: [backend/](backend/README.md) — воркер лицензий
и платежей, [backend-vps/](backend-vps/README.md) — прокси к ИИ,
[motion/](motion/README.md) — рендер рекламного ролика. После правок в
`backend-vps/server.js` запускайте `npm run sync:vps`, иначе CI упадёт на
рассинхроне с копией внутри `backend-vps/setup.sh`.
